# Estructura de ClockGears Engine

* `editor/` — Interfaz estilo RPG Maker MZ, árbol de mapas, paleta de tiles, editor de eventos y base de datos RPG.
* `scene/` — Nodos 2D, sistemas de mapas, diálogos, menús y combate por turnos.
* `core/` — Núcleo en C++ del motor, serialización y gestión de datos.
* `drivers/` y `platform/` — Backends gráficos y soporte multiplataforma.
